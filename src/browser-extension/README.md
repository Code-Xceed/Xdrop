# Xdrop Browser Companion Extension

Allows 1-click importing of video and audio directly from your browser into **DaVinci Resolve**, **Adobe Premiere Pro**, and **After Effects**.

---

## Installation (Chrome / Edge / Brave)

1. Open `chrome://extensions` (or `edge://extensions` in Edge, `brave://extensions` in Brave).
2. Enable **Developer mode** (toggle in top right).
3. Click **Load unpacked**.
4. Select the `apps/browser-extension` folder inside this repository.

---

## How to Use

- **Context Menu**: Right-click any video or link on YouTube, TikTok, Instagram, X/Twitter, or Reddit, and select **Send to Xdrop (Active Editor)**.
- **Extension Popup**: Click the Xdrop icon in your browser toolbar to send the active tab URL directly into your open project bin.
